# 💳 Credit Card Sales Analysis

## 📌 Project Overview

This project focuses on analyzing credit card transaction and customer data to understand sales performance, customer spending behavior, and revenue trends. The analysis helps identify important business patterns, evaluate transaction performance, and generate actionable insights to support data-driven decision-making.

The project demonstrates practical data analytics skills, including data cleaning, data transformation, exploratory data analysis, KPI tracking, and data visualization.

## 🎯 Project Objectives

- Analyze overall credit card transaction revenue.
- Understand customer spending behavior and preferences.
- Identify top-performing customer segments.
- Analyze transaction trends across different time periods.
- Compare revenue by card category and transaction type.
- Evaluate customer demographics and purchasing patterns.
- Identify key factors influencing business performance.

The data preparation process includes:

## 📊 Exploratory Data Analysis (EDA)

The analysis focuses on:

- Overall revenue and transaction performance.
- Monthly and weekly revenue trends.
- Revenue by credit card category.
- Customer spending by age group and gender.
- Revenue by income group and occupation.
- Transaction volume and average transaction value.
- Customer segment performance.
- Identification of high-performing categories and trends.

## 📈 Key Performance Indicators (KPIs)

- **Total Revenue:** Total revenue generated from credit card transactions.
- **Total Transactions:** Number of transactions recorded.
- **Total Transaction Amount:** Sum of transaction amounts.
- **Average Transaction Value:** Average amount per transaction.
- **Total Customers:** Number of unique customers.
- **Interest Earned:** Total interest earned, if available.
- **Monthly Revenue Growth:** Change in revenue compared with the previous month.
